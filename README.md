# Draft Survey Calculator — legal pages

Hosts the privacy policy for the **Draft Survey Calculator** mobile app
(`ua.od.and.draftsurvey`), as required by Google Play and the App Store.

- Live page: https://andmyr.github.io/draftsurvey-privacy/
- Contact: Draft_Survey@and.od.ua

This repository is public **only** so that GitHub Pages can serve the policy over HTTPS
free of charge. It contains no application source code.

The source of truth for the text is `docs/privacy-policy.md` in the private application
repository; this page is generated from it. If the text changes there, update it here too —
a published policy that disagrees with the app is worse than none.
